技术与部署

站点由静态生成脚本一次性产出，所有文件平铺在根目录，与 index.html 同级，路径只有一层，不依赖子目录，也不使用 URL 重写。上传到 GitHub Pages 后即可直接访问，无需任何后端环境。

页面结构遵循基础 SEO 规范：每页唯一标题与 H1、独立 description、canonical、面包屑、文章间互链、以及 sitemap.xml 与 robots.txt。正文全部写在 HTML 里，不依赖 JavaScript 渲染，便于搜索引擎抓取。

站内搜索页使用前端脚本在本地索引中匹配标题、摘要与标签，索引同样内置在页面中，不发起外部请求。
